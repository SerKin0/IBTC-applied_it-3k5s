# Домашние задания по предмету 3 курса - "Прикладные информационные технологии"

В репозитории сохранены решения домашних заданий с практик.

## Система хранения

Основным заданием данной дисциплины является не решение заданий, а разработка своего MVP, поэтому некоторые домашние задания затрагивают тему персональных проектов студентов (таблицы, схемы, описания и другое). Поэтому нумерация домашних работ идет по мере получения **практических** заданий.

- Решения домашних заданий отмечаются как:
```
📂 .\1_homework
📂 .\2_homework
...
```
- Задания в классе:
```
📂 .\1_classwork
📂 .\2_classwork
...
```
